# Inter-shop with Sequelize and server

# Command sequelize
```bash
"dbcreate": "npm run sequelize db:create",
```
```bash
"dbdrop": "npm run sequelize db:drop",
```
```bash
"dbmigrate": "npm run sequelize db:migrate",
```
```bash
"dbundo": "npm run sequelize db:migrate:undo",
```
```bash
"dbseed": "npm run sequelize db:seed:all",
```
```bash
"dbseedundo": "npm run sequelize db:seed:undo:all"
```

# Start server:
```bash
npm start
```
